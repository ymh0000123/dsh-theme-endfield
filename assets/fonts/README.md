## 这个仓库里怎么用它

`src/styles/sarkaz-font.css` 把本文件以 base64 内嵌进 `client.js`（单文件交付，不额外挂静态路由）。
`test/sarkaz-font.test.js` 用 SHA-256 校验内嵌副本与本文件一致，改字体时必须重新生成样式片段：

```bash
npm run build:font
```

## 字形与字符的对应

字体把萨卡兹字形直接放在拉丁字母与数字的码位上：`U+0020–U+007E` 一一对应，
大写字形与同码位小写共用（`A` 与 `a` 渲染同一个字形）。所以「写拉丁字母、用这个
字体渲染」就等于「写萨卡兹文字」，不需要任何转写表。

只覆盖 ASCII 与少量拉丁补充字符：汉字、`č` `š` `ğ` 这类带变音符的拼写没有字形，
会回退到系统字体。

## 一个已知前提

内嵌用的是 `data:` URL。如果宿主页面下发了不带 `font-src data:` 的 CSP，字形会被浏览器
拦下，底部字母行退回系统字体（那一行会变成普通拉丁字母）——不会报错，也不会破版。真要绕开，就得改走宿主路由
（`/theme-endfield/font/sarkaz.ttf`），代价是 `webServer` 缺席时功能会静默消失。
