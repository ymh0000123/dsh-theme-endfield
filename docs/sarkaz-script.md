# 萨卡兹文字：字形、词汇与在主题里的用法

> 一句话结论：**没有「萨卡兹语 ↔ 中文」的逐词翻译表可以直接背**，因为它是鹰角的自创语言，
> 现有材料都是社区从 PV、UI、国际服译名反推出来的。但**字形**是完整的：A-Z / 0-9 一一对应，
> 拿到字体就能读能写。本主题的「底部字母行」用的就是这套字形。

## 一、先分清两件事

社区里「Sarkaz 文字」常被混着说，其实是两层完全不同的东西：

| | 是什么 | 能否直接翻译 |
| --- | --- | --- |
| **字形**（萨卡兹古文字） | 一套书写系统，每个字形对应一个拉丁字母或数字 | 能。逐字替换即可，相当于替换式密码 |
| **语言**（萨卡兹语） | 有词根、后缀、语序的自创语言，出现在《明日方舟》集成战略「萨卡兹的无终奇语」的 PV 与曲名里 | 只能查到**部分**词汇与语法规律，没有官方词典 |

《终末地》里大量出现的是**字形**：UI 按钮、状态栏、PV 叠加层用它替换英文，教程附图里甚至用
「五笔块」和「Mod56 映射」把中文编码进去（见下文）。所以你在游戏里看到的那串符号，多数情况下
**转写成拉丁字母后仍是一串无意义的字母**——它是装饰性直替，不是句子。

## 二、字形对照：A-Z / 0-9 一一对应

字体把字形直接放在拉丁字母的码位上（`U+0041`–`U+005A`、`U+0030`–`U+0039`），大写字形与同码位
小写共用。对应的字形样式见 [assets/sarkaz-alphabet.png](../assets/sarkaz-alphabet.png)，或
[PRTS 泰拉文字条目](https://prts.wiki/w/%E6%B3%B0%E6%8B%89%E6%96%87%E5%AD%97) 的「萨卡兹古文字」一节。

三个读法上的坑：

- **可能被整体旋转 180°。** 游戏里常见「倒置式」排版，直接读会得到乱码，先把整块转回来。
- **可能是五笔块。** 把汉字的 86 版五笔编码按 2×2 排成字符块，再从左到右排列——转写成字母后
  要按五笔表回推汉字。
- **可能是 Mod56 映射。** 把汉字/数字/标点的 Unicode 码位对 56 取余再映射。官方教程与宣发用它
  生成「看起来像萨卡兹文」的演示文字，早期的映射表是固定的，后来改成了动态/随机。

## 三、词汇表（社区整理，节选）

词形按社区惯用拼写；`č` `š` `ğ` 是音系记号，字体里**没有**这些字形（会回退成普通字母）。

| 词 | 释义 | 备注 |
| --- | --- | --- |
| `kaz` | 家；人 | 复数 `kazam` |
| `kazdel` | 家园；卡兹戴尔 | `kaz` + `del` |
| `teekaz` | 提卡兹 | `tee`（我的）+ `kaz` |
| `sarkaz` | 萨卡兹，字面「无家之人」 | `sar-`（否定）+ `kaz` |
| `kerda` | 新的 | |
| `kerdem` | 新生 | |
| `pass` | 道路 | 复数 `passam` |
| `qe` | 我 | |
| `qui` | 希望 | 奎萨辛娜、奎萨图什塔等专名里出现 |
| `qlim` | 语言 | 复数 `qlimam`；借自阿拉伯语词根 k-l-m |
| `šanae` | 天空 | |
| `sarašul` | 好友 | 曲名 `Sura Saraǧul'tee`「起身吧，我的朋友」 |
| `tabulo` | 商店 | 借自拉丁语 |
| `tesauro` | 仓库 | 借自拉丁语 |
| `vul'fanasm` | 幻想 | 复数 `vul'fanasmam` |
| `wiš` | 愿望 | 维什戴尔 `Wiš'adel`「家之祈愿」 |
| `agašlehem` | 思想 | |
| `hal` | 仇恨 | |
| `nečatum` | 篇章 | 借自拉丁语 `necatum` |

**语法要点**（社区破译，非官方）：

- **修饰语在前，中心语在后**：不说「红色的苹果」，说「苹果-红色」。
- **复数后缀 `-am`**：`kaz` → `kazam`，`pass` → `passam`。
- **撇号 `'` 相当于 of**（闪语式的构造态），本身不发音：`Wiš'adel` = 家之祈愿。
- **动词有辅音词干**，后接 `-a` / `-e`，完成体 `-it`，被动 `-eliš`。
- 词汇来源混杂：闪语系词根 + 大量拉丁语借词 + 原创成分。

## 四、在主题里怎么用

本主题的用法是播报弹窗大字下方那行落款：**它不是固定串，而是由大字派生**（`31-thunder.js`
的 `thunderFooter()`）。播报词整串是拉丁字母时，落款就是它自己（转大写、去标点）；中文词
没有字形可套，落回与播报种类绑定的内置落款 `MISSION START` / `MISSION COMPLETE`。
**不开放编辑**——那一行是装饰落款，不是让用户输入目标语言的文本框；理由写在
[features.md](features.md) 的同名小节里。

要在别处用这套字形，写法是「写拉丁字母 + 指定 `Endfield Sarkaz` 字体」，仍然没有转写表：

| 拉丁字母 | 显示 | 含义 |
| --- | --- | --- |
| `KAZDEL` | 六个萨卡兹字形 | 家园 / 卡兹戴尔 |
| `KERDA KAZ` | 九个字形（含空格） | 新家园 |
| `MISSION START` | 十三个字形（含空格） | 任务开始（播报落款） |
| `SARKAZ` | 六个萨卡兹字形 | 萨卡兹 |
| `SURA SARAŠUL TEE` | 前两词是字形，`Š` 回退 | 起身吧，我的朋友 |

实现上只换字体、不做转写：字形与字符一一对应，所以「写什么字母就是什么字」，没有需要维护的
映射表。汉字与带变音符的拼写没有字形，按 `font-family` 栈回退到系统字体——混排中文时整行不会
消失，只是那几个字符不是萨卡兹字形。

字体是社区字体 **EndfieldByButan**（作者**罗醭坦**，[lhclbt/Endfield_Font](https://github.com/lhclbt/Endfield_Font)），
以 **CC BY-NC 4.0** 发布：可自由使用与二创、**不得商用**。它随 `client.js` 内嵌分发，来源与
许可边界见 [assets/fonts/README.md](../assets/fonts/README.md)，**不在本仓库 MIT 许可证的覆盖范围内**。
